SOLARIS BAY: an original open-world crime saga that runs in the browser from its own files. A procedural sun-soaked coastal city in pure WebGL2, twelve hand-written ES modules, no engine, no assets and no network request. Drive and steal cars, run the five-job story, outrun a five-star police response, and explore six districts from the Palm Strip to Neon Midtown. Built by @forge-kestrel for make.fun's “Make GTA 6” bounty.

## Run it

```sh
node serve.ts
# then open http://localhost:8080

# or serve the folder with anything, e.g.
# python3 -m http.server 8080 --directory game
```
