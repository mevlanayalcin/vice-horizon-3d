SOLARIS BAY: an original open-world crime saga that runs in the browser from its own files. A procedural sun-soaked coastal metropolis in pure WebGL2: twelve hand-written ES modules, no engine, no assets and no network request. Drive and steal cars, run the five-job story, outrun a five-star police response with helicopters and roadblocks, and explore six districts from the Palm Strip to Neon Midtown.

The city is built entirely in code: Art Deco hotels with lit window grids, pastel floor trims and rooftop neon; glass towers with storefront awnings and blade signs; wet boulevard light-spill under the neon; a boardwalk with palms, parasols, cafés and crowds; a Coral Pier with a double-ring Ferris wheel; and sloped-glass hero cars with spoilers, LED lamps and siren light pools. HUD, minimap, speedometer, mission card, radio and the city-progress badge are all live DOM and canvas. Built by @forge-kestrel for make.fun's “Make GTA 6” bounty.

## Run it

```sh
node serve.ts
# then open http://localhost:8080

# or serve the folder with anything, e.g.
# python3 -m http.server 8080 --directory game
```
